# myweather

Aplicacion y widgets meteorologicos para Android en Jetpack Compose con cero telemetria, sin claves comerciales y centrada en la ubicacion establecida por el usuario (por defecto Orizaba, Veracruz mediante Open-Meteo).

## Caracteristicas
- **Cero telemetria**: sin SDKs de analiticas, sin rastreo en segundo plano y sin permiso de ubicacion permanente.
- **Datos de alta resolucion (Open-Meteo)**: temperatura actual, sensacion termica, elevacion, pronostico por hora, ciclo solar, calidad del aire y proximos 7 dias.
- **4 Widgets de pantalla de inicio**: Clima Dinamico (2x2), Clima Minimal (2x2), Ciclo Solar (2x2) y Pronostico Completo (4x2 / 4x4).
